# Dev AI - Full-Stack Developer App

**NoVaJeeno/Dev-AI** — Eine vollwertige Entwickler-App mit KI-Agenten, Terminal, Build & Deploy.

## Features
- 3 KI-Agenten (Dev-Agent, Second-Agent, Self-Healing-Agent)
- GitHub-Integration mit Push/Clone/Repo-Management
- Echtes Terminal mit Build-Befehlen
- EAS Build & Deploy
- Sandbox-Engine für sicheres Code-Ausführen
- Self-Healing System mit automatischer Fehlerbehebung
- Expo & Native iOS Support
